API Control

[CENTRAL_C2_AUTOMATION]

Centralized command & control systems can audit or remotely reconfigure tool access policies across deployed agent nodes via the following standardized endpoints:

GET /api/v1/tools
Returns full tools policy JSON, timestamp, and audit metadata. Available on both Dashboard (:5150) and Host Bridge (:8990).
PUT /api/v1/tools
Applies batch tool policy updates from centralized C2 management servers. Persists atomically to disk.
POST /api/v1/tools/{id}/toggle
Instantly activates or locks down a specific capability (e.g. os_bridge or system_cli).
POST /api/v1/system/cli
Runs commands on underlying host OS CLI. Returns HTTP 403 Security Governance Error if system_cli is disabled.
